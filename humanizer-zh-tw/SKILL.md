# Humanizer 繁中台灣強化版

`humanizer`（英文版）抓的是英文 AI 特徵（em-dash、rule of three、AI vocabulary…）。**中文有另一套 AI 味那把尺量不到**：大陸用語、書面翻譯腔、的的不休、過度工整、缺語氣詞。這份補那個洞。

**用法**：先跑 `humanizer` 清英文毛病 → 再跑這份清中文台灣毛病。兩者互補、不重複。

---

## 🚫 先鎖你自己的語氣（別亂套人設）

去 AI 味 ≠ 亂加個性。網路很多「去 AI 味」教學叫你裝成「幽默直白帶點**毒舌**的 YouTuber」——**那是娛樂頻道配方**。套到教學/專業/品牌內容上會失真、甚至誤導讀者。動手前先鎖住**你這個場景真正該有的語氣**：

- **配合內容定調**：教學/科普 → 親切白話、**客觀不誇大**（只講做得到、查得證的，不為戲劇效果膨脹數字/後果/因果）；娛樂 → 才適合放飛。
- **有溫度 ≠ 毒舌**：可以有主觀評論與好惡、有個性，但**不酸讀者、不嘲諷、不製造對立**。
- **比喻要站得住**：生動比喻可以，但類比/因果不能為了好笑而失真，讀者照理解不會被誤導。
- **保留原意與資訊**：去 AI 味是改「怎麼講」，不是改「講什麼」；事實、數字、步驟一字不能跑。

> 一句判準：你是要「聽起來不像 AI」，不是「聽起來像另一個人」。鎖定的是你/品牌本來的聲音。

## 中文 AI 味 patterns（逐類抓＋改）

### 1. 大陸用語 → 台灣用語（最好抓、先掃）

AI 訓練語料大量簡體，繁中輸出常滲大陸詞。掃這張表：

| 大陸味 | 台灣講 | 大陸味 | 台灣講 |
|---|---|---|---|
| 質量 | 品質 | 優化 | 改善／調整 |
| 地道 | 道地 | 優質 | 好／優秀 |
| 視頻 | 影片 | 屏幕 | 螢幕 |
| 軟件／硬件 | 軟體／硬體 | 網絡 | 網路 |
| 信息 | 資訊／訊息 | 數據 | 資料／數據 |
| 默認 | 預設 | 激活 | 啟用 |
| 卸載 | 移除／解除安裝 | 登錄 | 登入 |
| 賬號 | 帳號 | 文件（指檔） | 檔案 |
| 服務器 | 伺服器 | 內存 | 記憶體 |
| 智能 | 智慧／智能 | 用戶 | 使用者／用戶 |
| 靠譜 | 可靠／穩 | 搞定／拿下 | 弄好／完成 |
| 花了…功夫 | 花了…工夫／力氣 | 走心 | 用心 |
| 牛（形容強） | 猛／強 | 頁面 | 頁面（可留）|

> 不確定就問自己「這詞我阿姨會不會這樣講」。

### 2. 書面腔連接詞 → 口語

AI 愛用書面連接詞串句，聽起來像在唸論文。

| 書面（AI） | 口語（台灣） |
|---|---|
| 然而／但是（句首連發） | 不過／可是／但 |
| 因此／故 | 所以／這樣一來 |
| 此外／另外（濫用） | 還有／再來 |
| 其實（濫用當發語詞） | 少用；真要轉折才用 |
| 換句話說／也就是說 | 講白一點／意思就是 |
| 值得一提的是／值得注意的是 | 直接講那件事，別鋪 |
| 首先…其次…最後 | 先…再…最後（或改因果） |
| 對…而言／對…來說 | 常可刪，或倒過來講 |

### 3. 正式動詞 → 白話動詞

| 正式（AI） | 白話 | 正式（AI） | 白話 |
|---|---|---|---|
| 使用 | 用 | 協助 | 幫 |
| 進行（+名詞） | 直接用動詞 | 具備 | 有 |
| 呈現 | 長怎樣／顯示 | 獲取 | 拿到／取得 |
| 點擊 | 點 | 執行 | 跑／做 |
| 能夠 | 能／會 | 進而 | 然後就 |

> 例：「進行一個資料夾的整理」→「整理一個資料夾」。「它具備自動分類的功能」→「它會自己分類」。

### 4. 句法 tells（最難自察、最出戲）

- **的的不休**：一句塞 3 個以上「的」。→ 拆句或刪。
  - ❌「一個你電腦裡的很重要的專案的資料夾」
  - ✅「你電腦裡一個資料夾，很重要那種」
- **過度工整/排比**：三句對稱、每句差不多長、頭尾呼應。AI 的招牌。→ **打破對稱**，改**因果推進**（因為…所以…沒想到…），長短句交錯。
  - ❌「它能整理檔案，它能撰寫摘要，它能開啟瀏覽器。」
  - ✅「它會自己整理檔案、順手把摘要寫好——欸它甚至會自己開瀏覽器，這個等下示範。」
- **翻譯腔句架**：`對…來說`、`所謂的X`、`這樣一個X`、`X的存在`、`使得`、`讓…成為可能`。→ 多半可刪或改主動。
  - ❌「所謂的 Cowork，指的是這樣一個能夠讓 AI 動你檔案的模式的存在。」
  - ✅「Cowork 就是讓 AI 動你電腦裡檔案的一個模式。」
- **被動與名詞化**：「被…所」「…的實現」「…的提升」。→ 改主動、改動詞。

### 5. 語氣詞與口語標記（加對，別亂加）

適度撒台式語氣詞讓文字有呼吸：**嘛、啦、齁、欸、喔、吧、耶、你看、我跟你講、對吧**。原則：
- **一句最多一個**，別堆（堆了假）。
- 放在**轉折、提醒、拉近距離**處，不是每句尾都掛。
- 提醒句最有效：「這個你先別急著點喔」「齁我跟你講，這步最多人卡」。

### 6. 具體取代抽象

AI 舉例愛抽象。換成**具體畫面**更像人：
- ❌「它能幫你處理很多繁瑣的工作」
- ✅「二十幾個檔名亂七八糟的會議記錄，它自己分好月份、還寫了摘要」

## 🎙️ TTS 旁白友善（若稿子是給語音合成唸的，必看）

很多「去 AI 味」建議教你「模仿人類思考的瑕疵」（贅字、停頓、自我修正）——**那是給真人口播的**。若你的稿子是**TTS 唸**的：

- **可以加**：語氣詞、白話短句、口語連接、具體描述。
- **不能加**：真人結巴、贅字重複、刻意省略、自我修正（「這個…那個…我是說…」）——TTS 唸出來會**卡字、變怪、出雜音**。
- **唸得順 > 看得順**：拗口的專名、中英夾雜的斷點，以「TTS 唸得清楚」為準。
- 破折號、刪節號少用——TTS 處理不穩。
- （若稿子是真人講的，這節不適用，真人瑕疵反而加分。）

## 生成方法：口述式（治本，不只潤飾）

AI 一次生成整段 prose，**天生偏書面**——潤飾是治標。治本是換生成方式：

1. **先列 bullet**：這段要講的重點條列（不要寫成句子）。
2. **假裝在跟朋友口述**：對著 bullet，用「欸我跟你講，這個是這樣…」的口吻**逐點講出來**，寫下你會怎麼講。
3. **再串**：把口述串成段，補轉場。
4. **然後才**跑本 skill 的 audit 收尾。

口述心態寫出來的，AI 味天生少一大半。

## Audit loop（打分 → 過 gate → 自我批判）

不是掃一遍就算，是**逐句過關卡 + 輸出前自我批判**。

**三種模式**：
- **write**：照「生成方法」寫新稿，寫完自動跑 audit。
- **audit**：對現有稿逐句打分——標出每一句踩了哪類（1 大陸用語 / 2 書面連接 / 3 正式動詞 / 4 句法 / 5 缺語氣 / 6 抽象 / TTS 不友善），給改法。
- **polish**：直接改，保留原意與資訊，只去 AI 味。

**輸出前自我批判（每句問一次）**：
1. **默唸測試**：這句唸出來，是「在跟人講話」還是「在唸稿」？卡舌/像唸文章＝書面腔，改。
2. 有沒有大陸用語漏網？
3. 有沒有「對…來說 / 所謂的 / 進行一個」這種翻譯腔架子？
4. 這段三句是不是一樣長、一樣結構（AI 工整）？打破它。
5. （TTS 稿）唸得順嗎？有沒有加了 TTS 會卡的真人瑕疵？
6. 語氣有沒有跑掉成毒舌/說教？拉回你該有的定調。

## Before / After（教學旁白情境）

**Before（中文 AI 味）：**
> 首先，Claude Cowork 作為一個強大的 AI 助理，能夠協助使用者進行檔案的整理與資訊的彙整。此外，對於新手用戶而言，它具備了非常直觀的操作介面，使得複雜的工作變得更加高效。值得一提的是，它甚至能夠開啟瀏覽器，這樣一個功能的存在，優化了整體的使用體驗。

**After（台灣口語、TTS 友善）：**
> Claude Cowork 能幫你整理檔案、把資料彙整成一份摘要。介面也單純，新手不太會卡。欸它甚至會自己開瀏覽器幫你做事——這個等一下實際跑給你看。

**改了什麼**：刪「首先/此外/值得一提」書面連接；「作為一個強大的…能夠協助…進行」→ 白話動詞；「對…而言」「這樣一個功能的存在」翻譯腔刪掉；「優化/高效」大陸味→改善/單純；打破三句工整改口語推進；加一個「欸」拉近＋收尾用具體「跑給你看」。

## Process

1. 先跑 `humanizer` 清英文 AI 特徵。
2. 跑本 skill 的 audit：逐句過 6 類 gate + TTS 檢查（若適用）。
3. polish：逐句改，保留資訊與意思。
4. 輸出前自我批判（默唸每句）。
5. 交回。**改完附「改了哪幾類」摘要**，方便回頭學。
