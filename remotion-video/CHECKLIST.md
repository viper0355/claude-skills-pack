# 交付前逐項打勾（每一項都要有實證）

## 時間軸
- [ ] `.tsx` 內 grep 不到手打秒數（只有 cue 編號與像素座標）
- [ ] 配音長度用 `ffprobe` 讀出，`durationInFrames` 由它算出
- [ ] 若改過旁白：新舊 SRT 的 cue 數比對過，位移量已套用到所有 tsx

## 畫面
- [ ] 沒有任何靜止畫面超過 10 秒
- [ ] 所有文字實測 ≥ 26px
- [ ] 直式素材等比置中，未拉伸
- [ ] 同源連續幕已合併 Sequence

## 隱私
- [ ] 去識別化清單逐項確認，用**不透明色塊**（非模糊）
- [ ] 色塊顏色取自抽幀量到的實際背景色

## 輸出
- [ ] 先渲靜幀確認版面，才渲全片
- [ ] `ffprobe` 顯示 `yuv420p` / `tv` / `bt709` / `bt709`
- [ ] 成品長度與配音長度一致（誤差 < 0.1 秒）

## 自審
- [ ] 全片每 15–30 秒抽一幀，**實際看過**
- [ ] 六類檢查逐項有結論
- [ ] 已知瑕疵誠實列出

## 回報
- [ ] 貼的是 `ffprobe` 實際輸出，不是預期值
- [ ] 附上實際看過的抽幀時間點
